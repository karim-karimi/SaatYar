# ساعت‌یار ۲.۰ — پروژه Android Studio

این نسخه بر اساس ماکاپ تصویری جدید بازطراحی شده است:
- داشبورد آبی/سفید با کارت‌های گرد
- ثبت ورود و خروج
- فعالیت‌های روزانه با دسته‌بندی و بازه زمانی
- تقویم شمسی
- گزارش روزانه/هفتگی/ماهانه
- تنظیمات ساعت موظف
- خروجی CSV
- صفحه شروع و درباره برنامه
- رابط راست‌چین فارسی
- فونت Noto Kufi Arabic به‌صورت داخلی برای نمایش فارسی (بدون دانلود جداگانه)

## اجرا
1. ZIP را Extract کنید.
2. پوشه `SaatYar-Pro` را در Android Studio با Open باز کنید.
3. Gradle Sync را کامل کنید.
4. در صورت درخواست، Android SDK 35 و Java 17 را نصب کنید.
5. برای نصب روی گوشی، USB Debugging را فعال کنید و Run بزنید؛ یا از Build > Build APK(s) فایل APK بسازید.

## نکته
اطلاعات اصلی در SQLite داخل خود گوشی ذخیره می‌شوند و برای ثبت اطلاعات نیازی به اینترنت نیست.
